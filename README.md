# LIFE JOURNEY — 人生を、遊ぼう。

就職・結婚・子育て・住宅購入・投資を楽しむ、オリジナルのオンライン人生すごろくです。人間とAIを合わせて **2〜6人** で遊べます。

## 起動

Node.js 22以上を使用します。追加パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで http://localhost:3000 を開いてください。開発時は `npm run dev` で変更を監視できます。ポートは `PORT` 環境変数で変更できます。

## 遊び方

1. 名前を入力してルームを作成します。
2. 友達に同じサーバーのURLと6桁のルームコードを共有します。
3. 友達は名前とコードを入力して参加します。空席にAIを追加することもできます。
4. ホストが開始します。自分の手番にサイコロを振り、転職・家族・投資のイベントで選択します。
5. 全員がゴールすると、純資産が多い順に結果が表示されます。

対戦中は盤面だけをスクロールし、イベント・操作・6人分のステータスは画面内に固定されます。過去の出来事は「履歴」から確認できます。スマートフォンでも操作できます。同じ端末で動作確認する場合は別ブラウザや別タブを使って参加できます。同じタブでのページ再読み込みは対戦に復帰します。

## ルール

- 72マス、初期資金300万円。給料マスは通過・停止のたび、昇給・副業込みの給料に0.8〜1.4倍（0.1刻みで抽選）を掛けて受け取れます。1万円単位で四捨五入します。
- 会社員：給料32万円。エンジニア：研修費80万円、給料48万円。起業家：開業費180万円、給料65万円。
- 結婚費60万円、子育て費1人40万円（最大3人）、住宅220万円（評価額260万円）。
- 投資信託の初期価格は1口40万円。毎ラウンド−12〜＋15万円で変動し、10〜100万円の範囲に収まります。投資マスで2口購入・全口売却・借入返済を選べます。
- 費用が現金を上回ると不足分を自動借入。未ゴールのプレイヤーには毎ラウンド5%の借入利息（切り上げ）。投資の購入には借入を使えません。
- ゴール時に退職金150万円、全員ゴール後に結婚祝い100万円、子ども1人につき70万円を加算します。
- 純資産＝現金＋投資評価額＋債券評価額＋住宅評価額−借入。

## 拡張されたイベントと選択

- 離婚マスは盤面に2か所。止まった既婚者は離婚し、独身なら変化なし。費用はなく配偶者がいなくなり、子どもは0人になります。住宅は維持します。家族マスで再婚できます。最後の結婚祝い100万円は終了時に既婚の場合のみ、子ども祝いは終了時の人数×70万円を加算します。

- 盤面は72マス。各区間でキャリア・家族・投資・学び・健康・余暇・給料日・イベントの配置をシャッフルします。全参加者には同じ盤面が配信されます。
- 36種類の専用イベントをシャッフルした山札から引きます。ルーム内で一巡するまで重複せず、山札を作り直す際も直前のイベントを連続させません。それぞれ2つの固有の選択肢があります。
- 職業は6種類（会社員、デザイナー、エンジニア、料理人、起業家、医師）。副業・昇進試験・資格取得・大学院での学びにより給料を増やせます。
- 投資信託の1口購入・1口売却、債券（100万円で購入、評価額120万円、途中売却不可）、住宅売却も選択できます。
- 健康マスで50万円の保険に加入すると「保険対象」と書かれたトラブル費用が半額になります。投資や挑戦の損失は対象外です。
- 旅行・趣味・休養・地域活動で幸福を獲得。幸福は0未満にならず、全員ゴール時に1pt＝5万円を現金へ加算します。
- 中央の共有カードに選択中の出来事と直前の結果を表示。全員が選択肢を閲覧でき、履歴にはプレイヤー名・選んだ行動・現金や給料などの増減を残します。
- 所要時間の目安は25〜45分です。

## オンラインで共有する場合

このアプリには対戦サーバーが含まれます。全員が同じサーバーへ接続してください。Codespacesではポート3000を転送し、共有相手がアクセスできる設定のURLを使用します。それ以外ではNode.jsの常駐プロセスとSSE通信に対応したホスティングに配置してください。静的サイト専用ホスティングには対応しません。

現段階ではルームをメモリに保持するため、サーバー再起動で対戦データは消えます。複数サーバー間の状態共有、アカウント、ランダムマッチは未実装です。参加者が接続を切った場合、その人の手番は復帰まで待機します。未接続かつ24時間更新のないルームは削除されます。

## テスト

```sh
npm test
```

ゲームルールとHTTP/SSEによる6人参加、参加上限、手番・ホスト権限を検証します。HTTPテストはローカルポート3199を使用します。

## 構成

- `server.js`：HTTP API、SSE配信、ルーム、AIの手番処理
- `game.js`：サーバー側のゲーム進行とルール
- `events.js`：36種類の選択型イベント
- `public/`：日本語UI（HTML / CSS / JavaScript）
- `test/`：Node.js標準テストランナーによる検証
